# Reporting problems

Report security or integration problems through [Silicon LogiX contact](https://www.siliconlogix.it/contatti). Include application version, platform and steps to reproduce. Do not post customer firmware, credentials or proprietary product data publicly.

The local API binds to loopback only. USB serial connects only when explicitly opened. Customer DLLs execute in the application process and are not sandboxed; load code you control. This is a software demonstrator with no physical actuator interface or safety certification.
